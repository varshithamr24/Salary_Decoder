# Salary_Decoder

A Python-based data analytics project that cleans, transforms, and analyzes salary data to uncover compensation trends across the Bengaluru tech industry.

📌 Project Overview

Salary Decoder is an exploratory data analysis (EDA) project built using Python. The project analyzes a dataset of over 1,000 Bengaluru tech professionals to identify salary patterns based on job role, experience, company type, education tier, and technical skills.

The primary objective is to convert messy HR data into meaningful business insights that can help job seekers, recruiters, and analysts better understand salary trends.

---

🚀 Features

- Load and inspect raw salary data
- Clean inconsistent and missing values
- Standardize job roles, company types, and education tiers
- Convert salary values from multiple formats into LPA
- Perform Exploratory Data Analysis (EDA)
- Compare salaries across different job roles
- Analyze salary growth based on experience
- Measure skill premiums for various technologies
- Compare salaries across company types
- Identify underpaid professionals using group median analysis
- Generate a structured salary intelligence report
